# MSMP — Project Instructions

This file defines team-shared architecture, conventions, workflows, and guidelines for the MSMP modpack.

## CurseForge Export Conventions

To comply with CurseForge distribution policies and avoid bloated distribution archives, adhere to the following packaging rules:

- **CurseForge-Hosted Projects:** Mod jar files belonging to CurseForge-hosted projects **MUST NOT** be added directly to the zip file overrides.
- **Reference in Manifest:** These files must instead be referenced by their project and file ID in the `manifest.json` file generated by the CurseForge App during a profile export.
- **Specifically Affected Mods:**
  - `overrides/mods/plasmovoice-neoforge-1.21.1-2.1.13.jar`
  - `overrides/mods/alexsmobs-1.22.17.jar`
  - `overrides/mods/dungeons-and-taverns-v4.4.4.jar`
